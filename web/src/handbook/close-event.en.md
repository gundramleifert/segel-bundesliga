## Close an event, or call it off

*Closing* is the last block of the event's panel (*Administration*, tab *Events*,
*Manage*), for the event's organizers — a race officer has no access to *Administration*
and asks an organizer to close the event. It shows only what applies now
and never asks for confirmation: everything here is one press to undo and deletes
nothing.

![The *Closing* block of a running event: *Racing is over* ①, *Call the event off* ②](shot:help-close-event)

### Racing is over {#close-event-finish}

1. Press *Racing is over* ①. The event is now final.

- Only a running event can be declared over; before the start the panel says so.
- Not every race has to be sailed: a day that lost its last flights to the wind is over
  when you say so.
- Nothing new is fixed, and results stay editable — a protest heard weeks later still
  lands on a final event.
- Publication does not change.

### Call the event off {#close-event-cancel}

1. Press *Call the event off* ② — before the start or halfway through the day.

- Nothing is deleted: the pairing list and any results stay as they are.
- A called-off event counts in no series table, and nobody gets the points for a missed
  event ([scoring](#terms-scoring)): a called-off regatta costs nobody anything.
- The event stays published if it was.

### Take it back {#close-event-reopen}

A closed event shows one button:

- *Resume racing* — a final event is running again.
- *Reinstate the event* — a called-off event is planned again; start it again with
  *Start event* ([start](#run-event-start)).
