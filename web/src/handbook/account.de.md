## Ihr Konto

Ein Konto pro E-Mail-Adresse, gleich wie Sie sich anmelden. Die Anmeldung legt nie ein
Konto an: Sie legen es selbst mit *Konto anlegen* an — weder Ihr Verein noch die
Geschäftsstelle kann das für Sie tun.

### Konto anlegen {#account-register}

Auf der Anmeldeseite als Reiter *Konto anlegen*, wo die Seite das zulässt.

1. Geben Sie *Ihr Name* und *E-Mail-Adresse* ein und tippen Sie auf *Konto anlegen*.
2. Tragen Sie den 6-stelligen Code aus der E-Mail unter *Einmalcode* ein und tippen Sie
   auf *Anmelden*. Der Code gilt zehn Minuten.

Ergebnis: Sie sind bei Ihrem eigenen Personendatensatz angemeldet, ohne Verein und ohne
Rolle. Der Admin eines Vereins nimmt Sie dann über diese Adresse als Mitglied auf, oder Sie
bitten einen Verein um Aufnahme ([Ihr Verein](#my-space-club)). Die Seite
verrät nie, ob zu einer Adresse schon ein Konto besteht; eine Registrierung mit einer
solchen Adresse ändert daran nichts.

### Anmelden {#account-sign-in}

- *Passwort*: *E-Mail-Adresse*, *Passwort*, *Anmelden*.
- *Code per E-Mail*: *Code senden*, dann den Code. Er gilt einmal, zehn Minuten lang;
  nach fünf falschen Eingaben ist er ungültig – tippen Sie auf *Code erneut senden*.

Eine fehlgeschlagene Anmeldung mit Passwort lautet immer gleich, egal aus welchem Grund.
Nach fünf Fehlversuchen ist das Passwort für 1, dann 5, dann 15 Minuten gesperrt; ein
Code per E-Mail funktioniert weiterhin und hebt die Sperre auf.

### Passwort festlegen, ändern oder entfernen {#account-password}

[*Ich* › *Profil & Konto*](place:profile.account) → *Anmeldewege*. Ihre Adresse muss
bestätigt sein – eine Anmeldung mit Code erledigt das.

- Zum ersten Mal: unter *Passwort festlegen* ① eintippen, dann die Schaltfläche
  *Passwort festlegen* ②. 12 bis 128 Zeichen, sonst keine Regel.
- Ändern: *Aktuelles Passwort* und *Neues Passwort*, dann *Passwort ändern*. Ein falsches
  aktuelles Passwort zählt als Fehlversuch.
- *Passwort entfernen*: Der Code per E-Mail bleibt Ihr Weg hinein.
- Vergessen: *Passwort vergessen? Mit Code anmelden*, dann hier ein neues festlegen.

![Anmeldewege ohne Passwort: das Feld ① und *Passwort festlegen* ②](shot:help-account-password)

### Konto beenden {#account-delete}

[*Ich* › *Profil & Konto*](place:profile.account) → *Mein Konto beenden* → *Ja, beenden*.

> **Achtung:** Danach können Sie sich nicht mehr anmelden. Jede Person hat ein Konto, es
> wird daher abgeschaltet, nicht gelöscht.

| Geht | Bleibt |
|---|---|
| die Anmeldung: Anmeldewege und Passwort | das Konto, abgeschaltet, und Ihr Personendatensatz: Ihr Name in Kadern, Crews und Ergebnissen, Ihre Bestätigungen des Haftungsausschlusses, Ihre Vereinsmitgliedschaften |
| jede Rolle | bereits eingereichte Abrechnungen, beim Verein, der sie bezahlt |
| Ihre Dokumente, Ihre Bankverbindung und nicht eingereichte Abrechnungen | Bestätigungen, die Sie für andere erfasst haben |

### Sprache und hell oder dunkel {#account-look}

Vor der Anmeldung stehen in der oberen Zeile die Sprache und *Anmelden*. Danach öffnet
Ihr Konto *Konto und Einstellungen*: *Mein Bereich*, *Mein Profil*, *Ligabüro*, wenn Sie
eine Rolle auf der ganzen Seite haben, *Hilfe* (*Hilfe zu dieser Seite*, wo die Seite eine eigene hat) und *Sprache*.

![Das Kontomenü einer Organisatorin oder eines Organisators](shot:help-account-menu)
 In der oberen Zeile, neben der Sprache oder Ihrem Konto, schaltet die
Sonne oder der Mond die ganze Seite hell oder dunkel — *Hell darstellen*, *Dunkel darstellen*. Alle beginnen mit
dunkel; Ihre Wahl bleibt auf diesem Gerät.
